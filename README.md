# AD Robot time-series chart

Независимый SVG-компонент, который принимает четыре последовательности данных и рисует их как `area`, `spline`, `line` и `bar`. При наведении показывается общая подсказка по ближайшей дате.

## Запуск

Нужен Python 3:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

Сборка и внешние зависимости не требуются.

## Инициализация

```js
renderTimeSeriesChart(document.getElementById("chart"), {
  dates: ["09.06.2026", "10.06.2026", "11.06.2026"],
  area: [12, 26, 38],
  spline: [6, 22, 32],
  line: [5, 18, 34],
  bar: [2, 4, 1]
});
```

Все массивы должны иметь одинаковую длину и содержать минимум две точки.
